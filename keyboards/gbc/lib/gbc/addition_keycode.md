# GBC24 追加キーコード一覧

GBC24で使用できる独自キーコードの一覧です。  
RemapまたはVIAでキーに割り当ててご使用ください。  

## 1. ジョイスティック

### キーコード一覧

| キーコード | 説明 |
|------------|------|
| `JOY_DIGI` | デジタル4方向入力に切り替え（初期設定） |
| `JOY_MOUS` | マウス入力に切り替え |
| `JOY_ANLG` | アナログ軸入力【DirectInput】に切り替え |
| `JOY_SPD_UP` | マウス最大速度を上げる |
| `JOY_SPD_DN` | マウス最大速度を下げる |
| `JOY_DZ_UP` | 現在のモードのデッドゾーンを広げる（鈍くする） |
| `JOY_DZ_DN` | 現在のモードのデッドゾーンを狭める（敏感にする） |
| `JOY_DZ_RST` | 3モードすべてのデッドゾーンを既定値に戻す |
| `CFG_SHOW` | 現在の設定値をテキストとして入力する |

### 入力モード

ジョイスティックは、用途に合わせて次の3つのモードに切り替えられます。

- **デジタルモード（初期設定）**  
  スティックを倒すと、上下左右の各方向に割り当てたキーが入力されます。  
  お絵描きソフトのショートカットなど、キー入力による操作に使えます。  
  `JOY_DIGI` で切り替えます。  

- **マウスモード**  
  スティックを倒した方向にマウスカーソルが移動します。  
  ジョイスティックでマウスカーソルを操作したい場合に使えます。  
  `JOY_MOUS` で切り替えます。  

- **アナログモード（ゲーム向け）**  
  スティックを倒した方向と傾きの大きさを、アナログ軸の入力として送信します。  
  DirectInputのアナログスティック入力に対応したゲームでの使用を想定しています。  
  `JOY_ANLG` で切り替えます。  

入力モードは保存されません。電源を入れるたびにデジタル4方向モードから始まります。  

### マウス最大速度の調整

`JOY_SPD_UP` / `JOY_SPD_DN` で、マウスモード使用時の最大速度を調整できます。  
設定できる値は 1, 5, 10, 15, … , 50 で、1回押すごとに1段階ずつ変わります。初期値は15です。  
（例：初期値15から下げると 10 → 5 → 1、1から上げると 5 → 10 → 15）

### デッドゾーンの調整

デッドゾーンは、スティックを中央から少し倒しても入力されない範囲です。  
広げると大きく倒すまで反応しなくなり、狭めると小さな動きでも反応するようになります。

`JOY_DZ_UP` / `JOY_DZ_DN` は、**その時アクティブなモード**のデッドゾーンを1回あたり2%ずつ変更します。  
調整したいモードに `JOY_DIGI` / `JOY_MOUS` / `JOY_ANLG` で切り替えてから操作してください。

| モード | 調整範囲 | 初期値 | 段階数 |
|--------|----------|--------|--------|
| デジタル | 6〜90% | 54% | 43段階 |
| マウス | 4〜90% | 24% | 44段階 |
| アナログ | 2〜90% | 12% | 45段階 |

`JOY_DZ_RST` を押すと、3モードすべてのデッドゾーンが初期値に戻ります。

デッドゾーンの%は、モードによって基準が異なります。

- デジタル / マウス：スティックの実際の可動域（中心からカバーに当たるまで）に対する割合
- アナログ：アナログ軸の最大値（フルスケール）に対する割合

デジタルモードで調整しているのは、入力が始まる位置（センター判定しきい値）です。  
上下左右のどの方向かを判定するしきい値は、この値に連動して自動調整されます。

### 設定の保存

マウス最大速度と各モードのデッドゾーンは、変更から約2秒後に自動でEEPROMへ保存されます。  
手動での保存操作は不要です。

入力モードは保存されません。

### 設定値の確認

メモ帳などのテキストエディターを開き、日本語入力（IME）をOFFにしてから `CFG_SHOW` を押してください。  
現在の設定値が1項目1行で入力されます。

#### 出力例

```
GBC24 joystick
mode            mouse
mouse speed     15 / 50
deadzone digi   54%
deadzone mouse  24%   <- current
deadzone analog 12%
eeprom          saved
```

#### 各項目の意味

| 項目 | 意味 | 表示される値 |
|------|------|------|
| `mode` | 入力モード | `digi`（デジタル4方向）／ `mouse`（マウス）／ `analog`（アナログ軸） |
| `mouse speed` | マウス最大速度（現在値 / 上限） | `1`〜`50` / `50` |
| `deadzone digi` | デジタルモードのデッドゾーン | `6%`〜`90%` |
| `deadzone mouse` | マウスモードのデッドゾーン | `4%`〜`90%` |
| `deadzone analog` | アナログモードのデッドゾーン | `2%`〜`90%` |
| `<- current` | 現在のモードのデッドゾーンに付く印 | ― |
| `eeprom` | 保存状態 | `saved`（保存済み）／ `auto saving`（変更直後で、約2秒後に自動保存される） |

#### 確認時の注意

- 1項目ごとにEnterキーを送って改行します。  
- チャット欄やコマンドプロンプトで押すと、送信や実行が行われてしまうのでご注意ください。  
- 日本語入力がONのままだと、かなに変換されて入力されます。  
- 出力には、US配列・JIS配列のどちらのPCでも同じ文字になる記号だけを使用しています。  

## 2. トラックボール

以下のキーコードは、オプションのReexトラックボールユニットを取り付けた場合にご利用いただけます。

### キーコード一覧

| キーコード | 説明 |
|------------|------|
| `REC_RST` | センサー設定を初期値に戻す（保存はしない。詳細は後述） |
| `REC_SAVE` | 現在のセンサー設定をEEPROMに保存 |
| `CPI_I100` | CPIを100増加（最大3500） |
| `CPI_D100` | CPIを100減少（最小100） |
| `CPI_I1K` | CPIを1000増加（最大3500） |
| `CPI_D1K` | CPIを1000減少（最小100） |
| `SCRL_TO` | 押すたびにスクロールモードのON/OFFを切り替え |
| `SCRL_MO` | 押している間だけスクロールモード |
| `SCRL_DVI` | スクロール除数を1つ上げる（最大 7 = 1/64、最も遅い） |
| `SCRL_DVD` | スクロール除数を1つ下げる（最小 1 = 1/1、最も速い） |
| `SSNP_VRT` | スクロールスナップを垂直方向に固定 |
| `SSNP_HOR` | スクロールスナップを水平方向に固定 |
| `SSNP_FRE` | スクロールスナップを無効化（自由スクロール） |
| `AML_TO` | 自動マウスレイヤーのON/OFFを切り替え |
| `AML_I50` | 自動マウスレイヤーのタイムアウトを50ms増加（最大1000ms） |
| `AML_D50` | 自動マウスレイヤーのタイムアウトを50ms減少（最小100ms） |
| `CFG_SHOW` | 現在の設定値をテキストとして入力する |

### 設定の保存・リセット

トラックボールの設定は、`REC_SAVE` を押したときだけEEPROMに保存されます（自動保存はありません）。  
`REC_SAVE` を押さずに電源を切ると、最後に保存した値に戻ります。  

| 設定 | `REC_SAVE` で保存 | 初期値 |
|------|:----:|------|
| CPI | ○ | 500 |
| スクロール除数 | ○ | 4（1/8） |
| スクロールスナップ | ○ | 垂直 |
| 自動マウスレイヤーのON/OFF | ○ | OFF |
| 自動マウスレイヤーのタイムアウト | ○ | 650ms |
| スクロールモードのON/OFF | ×（電源を入れると常にOFF） | OFF |

`REC_RST` を押すと、CPI、スクロール除数、自動マウスレイヤーのON/OFF、およびタイムアウトが初期値に戻ります。  
スクロールスナップは `REC_RST` では初期値に戻りません。垂直方向に戻す場合は `SSNP_VRT` を使用してください。  

初期値に戻した状態を残したい場合は、リセット後に `REC_SAVE` を押してください。  
保存済みかどうかは `CFG_SHOW` で確認できます。  

### CPI（カーソル速度）

CPIを上げると、同じ量だけボールを転がしたときにカーソルが大きく移動します。  
CPIを下げると、細かい位置調整がしやすくなります。  

`CPI_I100` / `CPI_D100` で100ずつ、`CPI_I1K` / `CPI_D1K` で1000ずつ調整できます。  
設定範囲は100〜3500、初期値は500です。  

### スクロール

スクロールモードでは、ボールを転がすことで画面をスクロールできます。  

- `SCRL_TO` は、押すたびにスクロールモードのON/OFFを切り替えます。  
- `SCRL_MO` は、押している間だけスクロールモードになります。  

スクロールモードのON/OFFは保存されません。電源を入れると常にOFFになります。  

#### スクロール速度

`SCRL_DVI` / `SCRL_DVD` でスクロール除数を変更します。  
除数の設定値を上げるとスクロールが遅くなり、下げると速くなります。  

| 設定値 | 倍率 |
|--------|------|
| 1 | 1/1（最も速い） |
| 2 | 1/2 |
| 3 | 1/4 |
| 4（初期値） | 1/8 |
| 5 | 1/16 |
| 6 | 1/32 |
| 7 | 1/64（最も遅い） |

#### スクロールスナップ

スクロールする方向を制限できます。  

- `SSNP_VRT` は、垂直方向のスクロールに固定します（初期値）。  
- `SSNP_HOR` は、水平方向のスクロールに固定します。  
- `SSNP_FRE` は、方向の固定を解除します。  

### 自動マウスレイヤー

`AML_TO` で、自動マウスレイヤーのON/OFFを切り替えます。初期値はOFFです。  

ONの状態でトラックボールを転がすと、**レイヤー3**に自動で切り替わります。  
操作をやめてから設定時間（初期値650ms）が経過すると、元のレイヤーに戻ります。  

レイヤー3にマウスボタンやスクロールを割り当てておくことで、レイヤー切り替えキーを押さずにマウス操作ができます。  

#### 元のレイヤーに戻るまでの時間

`AML_I50` / `AML_D50` で、タイムアウトを50msずつ調整できます。  
設定範囲は100〜1000ms、初期値は650msです。  

#### レイヤー3に割り当てるキー

以下のキーは、トラックボールを止めた状態でもレイヤーを維持します。  
マウス操作を続けるためのキーとして扱われるためです。  

- マウスボタン（`KC_BTN1`〜`KC_BTN8`）、マウスカーソル移動・ホイールなどのマウスキー
- `SCRL_MO`
- 修飾キー（Ctrl / Shift / Alt / GUI）、および `LCTL(KC_C)` のような修飾キー付きのキー
- `MO(3)` / `TG(3)` / `TO(3)` などのレイヤー操作キー

上記以外のキーを割り当てた場合、押した時点でレイヤー3が解除され、下のレイヤーのキーが入力されます。  
ただし、GBC24の独自キーコード（`CPI_I100` や `CFG_SHOW` など）は、レイヤー3のキーとして実行されたうえでレイヤーが解除されます。  
トラックボールを動かしながら押した場合は、レイヤー3のキーが入力されます。  

そのため、レイヤー3には上記のキーを割り当てることを推奨します。  

なお、キーを押している間と、キーを離してから約200msの間は、トラックボールを動かしてもレイヤーが切り替わりません。  
タイピング中に手が触れてしまった際の誤動作を防ぐための仕様です。  

### 設定値の確認

メモ帳などのテキストエディターを開き、日本語入力（IME）をOFFにしてから `CFG_SHOW` を押してください。  
現在の設定値が1項目1行で入力されます。  

#### 出力例

```
GBC24 trackball
cpi             500
scroll mode     off
scroll div      4  1/8
scroll snap     vertical
auto mouse      on
aml timeout     650ms
eeprom          saved
```

#### 各項目の意味

| 項目 | 意味 | 表示される値 |
|------|------|------|
| `cpi` | トラックボールのCPI | `100`〜`3500`（センサーが検出できない場合は `none`） |
| `scroll mode` | スクロールモード | `on` ／ `off` |
| `scroll div` | スクロール除数とその倍率 | `1  1/1`〜`7  1/64` |
| `scroll snap` | スクロールスナップ | `vertical`（垂直）／ `horizontal`（水平）／ `free`（無効） |
| `auto mouse` | 自動マウスレイヤー | `on` ／ `off` |
| `aml timeout` | 自動マウスレイヤーのタイムアウト | `100ms`〜`1000ms` |
| `eeprom` | 保存状態 | `saved`（保存済み）／ `not saved, press REC SAVE`（未保存。`REC_SAVE` を押さないと電源OFFで元に戻る） |

#### 確認時の注意

- 1項目ごとにEnterキーを送って改行します。チャット欄やコマンドプロンプトで押すと、送信や実行が行われてしまうのでご注意ください。  
- 日本語入力がONのままだと、かなに変換されて入力されます。  
- 出力には、US配列・JIS配列のどちらのPCでも同じ文字になる記号だけを使用しています。  
- 自動マウスレイヤー（レイヤー3）で押すと、ほかの通常キーと同じくレイヤー3が解除されます。
