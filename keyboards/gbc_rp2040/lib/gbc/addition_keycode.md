# GBC24 追加キーコード一覧

GBC24で使用できる独自キーコードの一覧です。  
RemapまたはVIAでキーに割り当ててご使用ください（Vial版のファームウェアをお使いの場合はVialで割り当てます）。  

## 1. ジョイスティック

### キーコード一覧

| キーコード | 説明 |
|------------|------|
| `JOY_DIGI` | デジタル4方向入力に切り替え（初期設定） |
| `JOY_MOUS` | マウス入力に切り替え |
| `JOY_ANLG` | アナログ軸入力【DirectInput】に切り替え |
| `JOY_SPD_UP` | マウス最大速度を上げる |
| `JOY_SPD_DN` | マウス最大速度を下げる |
| `JOY_DZ_UP` | 現在のモードのデッドゾーンを広げる（鈍くする） |
| `JOY_DZ_DN` | 現在のモードのデッドゾーンを狭める（敏感にする） |
| `JOY_DZ_RST` | 現在のモードのデッドゾーンを既定値に戻す |
| `JOY_CALIB` | 短押し：キャリブレーション開始／確定、2秒長押し：既定値に戻す（「キャリブレーション」参照） |
| `CFG_SHOW` | 現在の設定値をテキストとして入力する |

### 入力モード

ジョイスティックは、用途に合わせて次の3つのモードに切り替えられます。

- **デジタルモード（初期設定）**  
  スティックを倒すと、上下左右の各方向に割り当てたキーが入力されます。  
  出荷時は上下左右に矢印キー、押し込みにEnterが割り当てられています。Remapで変更できます。  
  お絵描きソフトのショートカットなど、キー入力による操作に使えます。  
  `JOY_DIGI` で切り替えます。  

- **マウスモード**  
  スティックを倒した方向にマウスカーソルが移動します。  
  軽く倒すとゆっくり、大きく倒すほど速く動き、どの方向に倒しても同じ速さになります。  
  マウスボタン（`KC_BTN1` など）を押したままスティックを倒すと、ドラッグ操作ができます。  
  `JOY_MOUS` で切り替えます。  

- **アナログモード（ゲーム向け）**  
  スティックを倒した方向と傾きの大きさを、アナログ軸の入力として送信します。  
  斜め方向の入力にも対応しており、デッドゾーンを超えれば、わずかな傾きも出力に反映されます。  
  DirectInputのアナログスティック入力に対応したゲームでの使用を想定しています。  
  `JOY_ANLG` で切り替えます。  

入力モードは保存され、次に電源を入れたときも前回のモードから始まります（初期設定はデジタルモード）。  

### 中心位置について

ジョイスティックの中心位置は、USBケーブルを接続したとき（電源が入ったとき）に自動で設定されます。  
接続するときは、スティックに触れないでください。  

カーソルが勝手に動く、何もしていないのに方向キーが入力されるといった場合は、スティックに触れずにUSBケーブルを挿し直すか、`JOY_CALIB` で中心を取り直してください（「キャリブレーション」参照）。  
キャリブレーションを保存していても、中心位置は電源を入れるたびに取り直します（スティックの静止位置は挿し直すたびに少し変わるためです）。  
ただし、保存した中心位置から大きくずれていた場合（接続時にスティックに触れていた場合）は、保存した中心位置を使います。  

### キャリブレーション

`JOY_CALIB` で、可動域（カバーに当たって止まる端の位置）を実機で測り直して保存できます。  
保存されるのは上下左右の端の位置で、中心位置は毎回の電源投入時に自動で取り直します。  
次のような場合に使います。

- 挿し直さずに中心位置を取り直したい
- いっぱいまで倒してもマウスが最大速度にならない／アナログ軸が最大値にならない
- 逆に、いっぱいまで倒す手前で最大になってしまう

#### 手順

1. スティックから手を離した状態で `JOY_CALIB` を押します。  
   約0.5秒かけて中心位置を取得します。この間はスティックに触れないでください。  
2. スティックをカバーに当てながら、ゆっくり2〜3周回します。  
   上下左右の端まで確実に当ててください。  
3. もう一度 `JOY_CALIB` を押すと確定し、端の位置がEEPROMに保存されます。  

測定中（手順1〜3の間）は、ジョイスティックの入力（方向キー・マウス・アナログ軸）は出力されません。  
手順3を押さずに約30秒放置すると中断され、何も保存されません。  

#### 中心位置だけ取り直す

手順1のあとスティックを動かさずに手順3を行うと、端の位置はそのままで中心位置だけ取り直します（挿し直したときと同じ効果です）。  
液晶付きモデルでは、測定中は `CAL` の下に `CTR`（中心取得中）／`RNG`（可動域取得中）、確定後5秒間は `OK`／`CTR ONLY`／`NG`／`RST` が表示されます。  

#### 既定値に戻す

`JOY_CALIB` を2秒以上長押しすると、保存した端の位置を消して出荷時の値に戻り、中心位置もその場で取り直します（電源を入れたときの自動設定と同じ動作です）。  
長押ししている間はスティックに触れないでください。  

#### 失敗する場合

上下左右のいずれかが十分に倒されていない（出荷時の可動域の半分に満たない）と、確定時に失敗して何も保存されません。  
手順1の中心取得中にスティックに触れていた場合（中心が大きくずれた場合）も、その時点で失敗します。  
失敗した場合、中心位置も開始前の値に戻ります。  
`CFG_SHOW` の `calib` 行が `last failed` になっていたら、端までしっかり当てながらもう一度行ってください。  

中心から端までの距離の97%の位置で最大になるように計算されます。個体差や温度による変化があっても、端まで倒せば確実に最大になるようにするためです。  

### マウス最大速度の調整

`JOY_SPD_UP` / `JOY_SPD_DN` で、マウスモード使用時の最大速度（スティックをいっぱいまで倒したときの速さ）を調整できます。  
設定できる値は 1, 5, 10, 15, … , 50 で、1回押すごとに1段階ずつ変わります。初期値は15です。  
（例：初期値15から下げると 10 → 5 → 1、1から上げると 5 → 10 → 15）  
最大速度を1にしても、軽く倒したときや斜め方向にもカーソルは動きます。  
ただし最大速度を1にすると、倒し具合に関係なく一定の速さになります。

### デッドゾーンの調整

デッドゾーンは、スティックを中央から少し倒しても入力されない範囲です。  
広げると大きく倒すまで反応しなくなり、狭めると小さな動きでも反応するようになります。

`JOY_DZ_UP` / `JOY_DZ_DN` / `JOY_DZ_RST` は、**その時アクティブなモード**のデッドゾーンだけに作用します。  
`JOY_DZ_UP` / `JOY_DZ_DN` は1回あたり2%ずつ変更します。  
調整したいモードに `JOY_DIGI` / `JOY_MOUS` / `JOY_ANLG` で切り替えてから操作してください。

| モード | 調整範囲 | 初期値 | 段階数 |
|--------|----------|--------|--------|
| デジタル | 6〜90% | 54% | 43段階 |
| マウス | 4〜90% | 24% | 44段階 |
| アナログ | 2〜90% | 12% | 45段階 |

`JOY_DZ_RST` を押すと、現在のモードのデッドゾーンが初期値に戻ります。ほかのモードの値は変わりません。

デッドゾーンの%は、どのモードも「倒した方向の実際の可動域（中心からカバーに当たるまで）」に対する割合です。  
スティックは方向によって倒せる距離が少しずつ異なりますが、どの方向も同じ割合だけ倒したところで反応し始めます。  
また、スティックを倒した距離で判定するため、斜め方向も上下左右と同じ距離で反応し始めます。

デジタルモードで調整しているのは、入力が始まる位置です。  
上下左右のどの方向になるかは、上下と左右のうち大きく倒れているほうで決まります（斜め45°が境目です）。  
境目でキーが押したり離したりを繰り返さないよう、少し余裕を持たせています。

- 一度入力されると、入力が始まる位置より少し（可動域の4%）戻すまで、キーは押されたままです。
- 入力中に向きを変えたときは、境目の45°を少し越えるまで、元の方向のままです。

アナログモードでは、デッドゾーンを超えた位置から出力が0から滑らかに始まり、いっぱいまで倒すと最大値になります。  

デジタルモードでスティックを倒したまま `JOY_DZ_UP` / `JOY_DZ_DN` / `JOY_DZ_RST` を押すと、方向キーがいったん離され、押し直されます。  

### 設定の保存

入力モード、マウス最大速度、各モードのデッドゾーンは、変更から約2秒後に自動でEEPROMへ保存されます。  
手動での保存操作は不要です。  
キャリブレーションの結果は、確定した時点ですぐに保存されます。  

トラックボールユニットを取り付けた場合は保存方法が異なり、`REC_SAVE` を押したときだけ保存されます（「2. トラックボール」の「設定の保存・リセット」参照）。  

### 設定値の確認

メモ帳などのテキストエディターを開き、日本語入力（IME）をOFFにしてから `CFG_SHOW` を押してください。  
現在の設定値が1項目1行で入力されます。

#### 出力例

```
GBC24 joystick
mode            mouse
mouse speed     15 / 50
deadzone digi   54%
deadzone mouse  24%   <- current
deadzone analog 12%
center          541 501
range           248 787 223 737
span            284 238 269 228
calib           saved, last ok
eeprom          saved
```

#### 各項目の意味

| 項目 | 意味 | 表示される値 |
|------|------|------|
| `mode` | 入力モード | `digi`（デジタル4方向）／ `mouse`（マウス）／ `analog`（アナログ軸） |
| `mouse speed` | マウス最大速度（現在値 / 上限） | `1`, `5`, `10`, … , `50` / `50` |
| `deadzone digi` | デジタルモードのデッドゾーン | `6%`〜`90%` |
| `deadzone mouse` | マウスモードのデッドゾーン | `4%`〜`90%` |
| `deadzone analog` | アナログモードのデッドゾーン | `2%`〜`90%` |
| `<- current` | 現在のモードのデッドゾーンに付く印 | ― |
| `center` | 中心位置（X Y）：電源投入時または長押しリセット時に取得した静止位置 | ADC値（0〜1023） |
| `range` | 端の位置（X最小 X最大 Y最小 Y最大）：出荷時の値またはキャリブレーションで保存した値 | ADC値 |
| `span` | 可動域（X- X+ Y- Y+）：中心から端までの距離の97%。中心が変わるたびに計算し直されるので、電源を入れるたびに多少変わります | ADC値 |
| `calib` | キャリブレーションの状態 | `default`（出荷時の端の位置）／ `saved`（保存した端の位置を使用中）／ `saved center only`（端は出荷時、中心の参照値だけ保存）／ `running`（測定中）。続けて直前の結果 `last ok`／`last center only`／`last failed`／`last reset` が付くことがあります |
| `eeprom` | 保存状態 | `saved`（保存済み）／ `auto saving`（変更直後で、約2秒後に自動保存される） |

#### 確認時の注意

- 1項目ごとにEnterキーを送って改行します。  
- チャット欄やコマンドプロンプトで押すと、送信や実行が行われてしまうのでご注意ください。  
- 日本語入力がONのままだと、かなに変換されて入力されます。  
- 出力には、US配列・JIS配列のどちらのPCでも同じ文字になる記号だけを使用しています。  

## 2. トラックボール

以下のキーコードは、オプションのReexトラックボールユニットを取り付けた場合にご利用いただけます。

### キーコード一覧

| キーコード | 説明 |
|------------|------|
| `REC_RST` | センサー設定を初期値に戻す（保存はしない。詳細は後述） |
| `REC_SAVE` | 現在のセンサー設定をEEPROMに保存 |
| `CPI_I100` | CPIを100増加（最大3500） |
| `CPI_D100` | CPIを100減少（最小100） |
| `CPI_I1K` | CPIを1000増加（最大3500） |
| `CPI_D1K` | CPIを1000減少（最小100） |
| `SCRL_TO` | 押すたびにスクロールモードのON/OFFを切り替え |
| `SCRL_MO` | 押している間だけスクロールモード |
| `SCRL_DVI` | スクロール除数を1つ上げる（最大 7 = 1/64、最も遅い） |
| `SCRL_DVD` | スクロール除数を1つ下げる（最小 1 = 1/1、最も速い） |
| `SSNP_VRT` | スクロールスナップを垂直方向に固定 |
| `SSNP_HOR` | スクロールスナップを水平方向に固定 |
| `SSNP_FRE` | スクロールスナップを無効化（自由スクロール） |
| `AML_TO` | 自動マウスレイヤーのON/OFFを切り替え |
| `AML_I50` | 自動マウスレイヤーのタイムアウトを50ms増加（最大1000ms） |
| `AML_D50` | 自動マウスレイヤーのタイムアウトを50ms減少（最小100ms） |
| `CFG_SHOW` | 現在の設定値をテキストとして入力する |

### 設定の保存・リセット

トラックボールの設定は、`REC_SAVE` を押したときだけEEPROMに保存されます（自動保存はありません）。  
`REC_SAVE` を押さずに電源を切ると、最後に保存した値に戻ります。  
ジョイスティック使用時（変更から約2秒後に自動保存）とは保存方法が異なるのでご注意ください。  

| 設定 | `REC_SAVE` で保存 | 初期値 |
|------|:----:|------|
| CPI | ○ | 500 |
| スクロール除数 | ○ | 4（1/8） |
| スクロールスナップ | ○ | 垂直 |
| 自動マウスレイヤーのON/OFF | ○ | OFF |
| 自動マウスレイヤーのタイムアウト | ○ | 650ms |
| スクロールモードのON/OFF | ×（電源を入れると常にOFF） | OFF |

`REC_RST` を押すと、CPI、スクロール除数、自動マウスレイヤーのON/OFFとタイムアウト、スクロールスナップ（垂直）が初期値に戻ります。  

初期値に戻した状態を残したい場合は、リセット後に `REC_SAVE` を押してください。  
保存済みかどうかは `CFG_SHOW` で確認できます。  

### CPI（カーソル速度）

CPIを上げると、同じ量だけボールを転がしたときにカーソルが大きく移動します。  
CPIを下げると、細かい位置調整がしやすくなります。  

`CPI_I100` / `CPI_D100` で100ずつ、`CPI_I1K` / `CPI_D1K` で1000ずつ調整できます。  
設定範囲は100〜3500、初期値は500です。  

### スクロール

スクロールモードでは、ボールを転がすことで画面をスクロールできます。  

- `SCRL_TO` は、押すたびにスクロールモードのON/OFFを切り替えます。  
- `SCRL_MO` は、押している間だけスクロールモードになります。  

`SCRL_TO` でスクロールモードをONにしているときに `SCRL_MO` を押して離すと、ONのままです（`SCRL_MO` は押す前の状態に戻します）。  

スクロールモードのON/OFFは保存されません。電源を入れると常にOFFになります。  

#### スクロール速度

`SCRL_DVI` / `SCRL_DVD` でスクロール除数を変更します。  
除数の設定値を上げるとスクロールが遅くなり、下げると速くなります。  

| 設定値 | 倍率 |
|--------|------|
| 1 | 1/1（最も速い） |
| 2 | 1/2 |
| 3 | 1/4 |
| 4（初期値） | 1/8 |
| 5 | 1/16 |
| 6 | 1/32 |
| 7 | 1/64（最も遅い） |

#### スクロールスナップ

スクロールする方向を制限できます。  

- `SSNP_VRT` は、垂直方向のスクロールに固定します（初期値）。  
- `SSNP_HOR` は、水平方向のスクロールに固定します。  
- `SSNP_FRE` は、方向の固定を解除します。  

### 自動マウスレイヤー

`AML_TO` で、自動マウスレイヤーのON/OFFを切り替えます。初期値はOFFです。  

ONの状態でトラックボールを少し（ボールの表面で約0.75mm）転がすと、**レイヤー3**に自動で切り替わります。  
手が軽く触れた程度のわずかな動きでは切り替わりません。カーソルは、レイヤーが切り替わる前から動きます。  
レイヤー3になっている間は、わずかでも転がせばレイヤー3のままです。  
操作をやめてから設定時間（初期値650ms）が経過すると、元のレイヤーに戻ります。  

レイヤー3にマウスボタンやスクロールを割り当てておくことで、レイヤー切り替えキーを押さずにマウス操作ができます。  

#### 元のレイヤーに戻るまでの時間

`AML_I50` / `AML_D50` で、タイムアウトを50msずつ調整できます。  
設定範囲は100〜1000ms、初期値は650msです。  

#### レイヤー3に割り当てるキー

以下のキーは、押している間、トラックボールを止めていてもレイヤー3を維持します。  
マウス操作を続けるためのキーとして扱われるためです。  

- マウスボタン（`KC_BTN1`〜`KC_BTN8`）、マウスカーソル移動・ホイールなどのマウスキー
- `SCRL_MO`
- `MO(3)`

`TG(3)` / `TO(3)` は、もう一度押すまでレイヤー3を維持します。  

以下のキーは、押してもレイヤー3を解除しません。  
ただしレイヤー3を維持する働きはないため、トラックボールを止めたまま設定時間が経過すると、押している途中でも元のレイヤーに戻ります。  

- 修飾キー（Ctrl / Shift / Alt / GUI）
- `LCTL(KC_C)` のような修飾キー付きのキー

上記以外のキーを割り当てた場合、押した時点でレイヤー3が解除され、下のレイヤーのキーが入力されます。  
ただし、GBC24の独自キーコード（`CPI_I100` や `CFG_SHOW` など）は、レイヤー3のキーとして実行されたうえでレイヤーが解除されます。  
トラックボールを動かしながら押した場合は、レイヤー3のキーが入力されます。  

そのため、レイヤー3には上記のキーを割り当てることを推奨します。  

なお、キーを押してから約200msの間と、キーを離してから約200msの間は、トラックボールを動かしてもレイヤーが切り替わりません。  
タイピング中に手が触れてしまった際の誤動作を防ぐための仕様です。  
キーを200ms以上押し続けている間は、トラックボールを動かすと切り替わります。  
（ここでのキーは、上に挙げたレイヤー3を維持するキー・解除しないキー以外のキーです。）  

### 設定値の確認

メモ帳などのテキストエディターを開き、日本語入力（IME）をOFFにしてから `CFG_SHOW` を押してください。  
現在の設定値が1項目1行で入力されます。  

#### 出力例

```
GBC24 trackball
cpi             500
scroll mode     off
scroll div      4  1/8
scroll snap     vertical
auto mouse      on
aml timeout     650ms
eeprom          saved
```

#### 各項目の意味

| 項目 | 意味 | 表示される値 |
|------|------|------|
| `cpi` | トラックボールのCPI | `100`〜`3500`（センサーが検出できない場合は `none`） |
| `scroll mode` | スクロールモード | `on` ／ `off` |
| `scroll div` | スクロール除数とその倍率 | `1  1/1`〜`7  1/64` |
| `scroll snap` | スクロールスナップ | `vertical`（垂直）／ `horizontal`（水平）／ `free`（無効） |
| `auto mouse` | 自動マウスレイヤー | `on` ／ `off` |
